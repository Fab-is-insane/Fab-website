Fun Commands

Spice up your server with these fun commands!

🎉

  • -meme - Sends a random meme.
  • -joke - Tells a random joke.
  • -slap [user] - Slaps the [user] with random cartoon gifs.
  • -gis [query] - Searches using the Google Image Search API.
  • -roast - Roasts a user (all in good fun!).
  • -ig [username] - Fetches the instagram using [username]
